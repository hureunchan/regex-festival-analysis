# 대동제 및 해커톤 로그 분석

## 프로젝트 소개
정규표현식을 이용해서 대동제 및 해커톤 운영 로그에 있는 여러 데이터를 추출하는 프로그램입니다.

## 사용한 기능
- 이메일 주소 추출
- 휴대폰 번호 추출
- 학번과 학과 분리
- GitHub 주소 추출
- 쿠폰 코드 추출
- 부스별 매출액 계산

## 실행 방법
1. 로그 파일을 `data.txt`로 저장합니다.
2. `main.py`와 같은 폴더에 넣습니다.
3. 터미널에서 실행합니다.

```bash
python main.py
```

## 사용한 모듈
- re : 정규표현식을 사용하기 위한 모듈
- pathlib : 파일을 읽기 위한 모듈

## 결과
로그 파일에서 조건에 맞는 데이터를 추출하고 부스별 매출액과 전체 매출 합계를 출력합니다.

전체 매출 합계: 6,290,500원
